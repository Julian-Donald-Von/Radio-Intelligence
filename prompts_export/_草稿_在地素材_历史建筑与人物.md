# 在地素材 · 深挖第二辑：历史建筑 / 特殊的人 / 与歌相关（草稿 v2）

> 用户要求：继续狠狠头脑风暴，**历史建筑、特殊的人**、以及**其它和歌曲相关的东西**都要挖；
> 且**这块必须联网检索确定信息，不确定的不允许报**。

---

## 〇、先立"硬规则"（比维度表重要，因为它是**否决权**）

你说"必须联网检索确定信息，不确定不允许报" —— 这条要落成**可执行**的，否则模型会用
"模糊化"绕过核查。**模型最爱的三种绕法**，必须逐一点名封死：

| 绕法 | 例子 | 为什么必须封 |
|---|---|---|
| **软化词** | "据说""大概""好像""有种说法是" | 它把"没查到"包装成"查到了" |
| **模糊到不可证伪** | "这里的人都很爱音乐""这座城市有种独特的忧郁" | 无法核查 = 不可报（并非"中性"） |
| **半真半拼** | 真的建筑名 + 编的年代 | 最危险，因为看起来像真的 |

**草稿规则（拟进提示词）**：

> **在地内容一律"资料驱动"，且这是否决权（优先级最高）**
>
> 1. **只准写**《已检索到的在地事实》里**逐条列出**的内容。没列出的 — 无论你多确定 — **都不许写**。
> 2. **禁止软化词**：「据说 / 大概 / 好像 / 听说 / 有种说法 / 印象中」一律不许出现在在地内容里。
>    （用软化词 = 承认没查到 ⇒ 那就别写。）
> 3. **禁止不可核查的断言**：「这座城市很爱音乐」「这里的人有种疏离感」「这座城的气质」这类
>    **无法用来源证明**的话，一律不许写。
> 4. **半真半拼视同编造**：事实只准“整体引用”，不许把真名字配上自己记得的年份/细节。
> 5. **查不到就整段放弃在地** —— 回落到 B 级声音白描。**空着比模糊好。**
> 6. 文学化是允许的，但**只能装饰已核实的事实**：可以写「那口钟像被雨水泡过的铜」，
>    前提是**钟真的存在**且已列在资料里。

## 一、历史建筑与空间（深挖）

| 子类 | 能查到什么 | 与歌的接口 |
|---|---|---|
| **宗教/钟楼** | 教堂、寺庙、清真寺、钟鼓楼；建成年代、风格 | **声学**：教堂混响、钟声 —— 直接当声音意象 |
| **交通建筑** | 老火车站、码头、灯塔、轮渡、编组站 | 汽笛/潮声/离别 —— 漂泊类歌的最强锚点 |
| **演出空间** | 老戏院、老电影院、剧院、**现在的 livehouse** | "这首歌会在哪儿被听" |
| **工业遗存** | 水塔、烟囱、厂房、储气罐；**用途变迁**（厂→艺术区） | 工业挽歌、后朋、城市记忆 |
| **公共建筑** | 图书馆、老邮局、市政厅、医院、监狱、学校 | 年代感、制度感 |
| **城防/边界** | 城墙、城门、护城河、租界界碑 | 历史的层叠感 |
| **桥梁/地下** | 老桥、隧道、地下通道、防空洞 | **回声/延迟** = 声音比喻库 |
| **居住形态** | 里弄、大院、骑楼、苏式楼、城中村 | 生活质地 |
| **消失的建筑** | 被拆的老影院/老百货（若可核查） | 怀旧类歌（**注意：必须查到"确实存在过"，否则算编造**） |

**★ 一个高价值属性：声学** —— 建筑不只是形状，它是**声音的容器**：
教堂混响 / 隧道回声 / 木戏院的共鸣 / 地下通道的延迟。
⇒ 这类比拟**天生就在谈音乐**，是"在地→歌曲"最短的一条桥。

## 二、特殊的人（最强锚点库）

按**锚点强度**分级（越上面越强、越该用）：

| 级 | 类型 | 例 | 说明 |
|---|---|---|---|
| **S** | **歌手本人在该城的关系** | 出生地/出道地/常住地/在该城的演出史 | 最硬，且与"这首歌"天然同频 |
| **A** | **与当前歌手有真实关系的人** + 与城市有关 | 同厂牌、师承、合作、致敬对象 | 可做"隐秘联系"型锚点 |
| **B** | 该城出身的其他音乐人/乐队 | — | 与 S/A 并用才强，单用易泛 |
| **B** | 该城出身的文学家/诗人/导演/摄影师 | 意象与氛围的呼应 | 只作氛围，不推断动机 |
| **B** | **本地音乐场景的人** | livehouse 主理人、老唱片店主、本地厂牌 | "这幅声音有人在这座城守着" |
| **C** | 该城历史人物 | 与歌的题材相关时才用 | ⚠ 政治敏感人物一律避开 |
| **禁** | "这座城市的名人很多""这里的音乐氛围很好" | — | 不可核查 + 空话 |

**★ 最强的一类，单独标出**：**"这首歌与这座城的交集"**
（歌手在哪写的/录的/首演的；这首歌在该城有没有被翻唱/演出过）
—— 它是**唯一同时属于"歌"又属于"城"**的那类事实，一旦查到，一条口播就够了。

## 三、其它与歌相关的在地接口（再补一辑）

| 类 | 维度 | 说明 |
|---|---|---|
| **地方曲艺/乐器** | 评弹、二人转、秦腔、粤剧、南音、地方小调 | **与"中国风/民谣/采样"接口极强**；若歌曲采样了地方音乐，这是最高级锚点 |
| **方言音调** | 入声、儿化、九声六调 | 与歌手咬字的对比（"他唱这句时把入声吞掉了"） |
| **录音地点** | 专辑录制的城市/录音室 | 若与该城有关 ⇒ S 级 |
| **演出史** | 音乐节创办年、某场著名演出（可核查） | ⚠ 避开政治性集会 |
| **歌曲的再传播** | 翻唱/采样/MV 拍摄地（可核查） | 冷知识型锚点 |
| **声音地标** | 有轨电车、轮渡汽笛、报站声、厂区汽笛 | 直接可写的声音（B 级白描素材） |
| **物候与季节** | 花期/落叶/梅雨/供暖季 | 季节歌强相关（**月份敏感，别写错季**） |

## 四、检索落地（按域拆 query + 分级刷新）

一条 query 拿不到这么多，必须**按域拆**，并且**不同域刷新频率不同**（省钱关键）：

| 域 | query 示例 | 刷新频率 |
|---|---|---|
| 地理/自然 | `{city} 城市 水系 森林覆盖率 地形 气候` | **周**（几乎不变） |
| 城市史/产业 | `{city} 建城历史 支柱产业 变迁` | 周 |
| **历史建筑** | `{city} 历史建筑 老火车站 教堂 剧院 工业遗存` | 周 |
| **人物** | `{city} 音乐人 乐队 出身` + `{artist} {city} 演出 合作` | 周 |
| 地方曲艺 | `{city} 地方戏曲 曲艺 民谣` | 月 |
| 当下 | `{city} 今日天气 日落 物候` | **日** |
| 歌曲侧 | `{artist} {title} 创作背景 专辑 年份` | 每首 |
| 关系侧（转场） | `{artist} {next_artist} 合作 同厂牌` | 每对 |

**结构化落盘**（查到才列、列了才准用）：
```
【已检索到的在地事实（仅这些可用；未列出的一律不许写）】
城市：___
水系：___ | 森林覆盖率：___%（口径：___）
建城：___ | 支柱产业史：___
历史建筑：___（年代/风格/现状）
人物：___（与歌手/这首歌的关系：___）
地方曲艺/方言：___
本季物候：___
本地音乐场景：___
```
⇒ 与刚落的「联网补全」规则**天然咬合**：没列出的字段，模型不许自己补。

## 五、⚠️ 新增风险（第二辑）

1. **"消失的建筑"最难核** —— 写"这家老影院拆了"必须查到它**确实存在过**，否则是编造
   （模型很喜欢编"某家已消失的老店"）。
2. **人物最容易踩"关系编造"** —— "他和某歌手是朋友"这种**关系断言**必须查到，
   否则只写两边各自可核查的事实（"他出生于 A，而这位歌手在 B 出道"）。
3. **地方曲艺别张冠李戴** —— 二人转是东北的、南音是闽南的；写错地域比不写更糟。
4. **政治敏感人物/事件一律避开**（这是硬线，不进提示词的讨论范围）。
5. **物候/建筑是"年份敏感"的** —— 建筑现状（是否还开放）会变，来源要带年份。
